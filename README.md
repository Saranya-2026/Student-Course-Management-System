\# Student Course Management System



\## About the Project



The Student Course Management System is a Java-based application developed using JDBC to connect and interact with a database. It demonstrates how Java applications can perform database operations to manage student and course information.



\## Technologies Used



\* Java

\* JDBC (Java Database Connectivity)

\* Maven

\* SQL database



\## Features



\* Manage student information

\* Manage course information

\* Perform database operations using JDBC

\* Use DAO classes to organize database access

\* Establish database connections through Java



\## Project Structure



\* `Students.java` – Student-related data

\* `StudentsDao.java` – Student database operations

\* `Courses.java` – Course-related data

\* `CoursesDao.java` – Course database operations

\* `Enrollements.java` – Enrollment-related data

\* `EnrollementsDao.java` – Enrollment database operations

\* `Connections.java` – Database connection handling

\* `ConnectionPool.java` – Connection pooling implementation

\* `pom.xml` – Maven project configuration



\## How to Run



1\. Clone or download this repository.

2\. Open the project in an IDE such as Eclipse or IntelliJ IDEA.

3\. Configure your database connection details.

4\. Ensure the required database and tables are created.

5\. Build the Maven project and run the appropriate Java main class.
